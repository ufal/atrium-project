## Context
The `agent-skill` branches are flattened, trimmed derivatives of the default branches (§5) that
front the same API the pipeline ships. §12.2 keeps them current by porting default-branch
`service/` changes forward **by hand** — the branches were built independently and, for three of
five repos, share no git history with `test` at all.

That sync ran on 2026-07-24 and landed the #32 meta-contract. It has since gone stale: `test`
wired the **ATRIUM Document JSON accretion model** ([#13](https://github.com/ufal/atrium-llm-enrich/issues/13),
`docs/document_schema.md`) into the service layer of llm-enrich, translator and alto-postprocess,
and bumped every repo's `para_config.txt` version — which §4.6 surfaces through `/info`. The skill
branches therefore advertise an API that no longer matches what `test` serves.

Decisions locked (2026-07-29):
1. **Manual port now + build the transform** — close today's drift per the §12.2 checklist, and
   add the scripted `skill-ify` + drift-check §12.2 has been deferring, so the next sync is cheap.
   No force-push, branch history preserved.
2. **Port the accretion feature fully** — carry the optional `document_json` / `document_record`
   parameter and the accreted response field onto the skill branches, plus the runtime modules
   they need, so `/openapi.json` matches `test`.
3. **Enable the full contract check in CI** — implement `skill-validate.reusable.yml` step 4
   (endpoint diff + §4.1 `/info` envelope + `/health` shape against in-process `app.openapi()`).
4. Work lands on `claude/agent-skills-test-alignment-yowvdc`, cut **from `agent-skill`**, then
   merged to `agent-skill` per repo.

## Execution order
Cheapest-first, so the shared-file re-baseline and the CI change are proven before the hard case:
**nlp-enrich → page-classification → llm-enrich → translator → alto-postprocess**.

1. **Hub** — implement `skill-validate.reusable.yml` step 4; add `tools/skill_ify.py` +
   `tools/skill_drift_check.py`; update §5 (require `atrium_document.py` +
   `atrium_document.schema.json`) and §12.2 (manual → scripted); refresh `docs/skills_catalog.md`.
2. **Shared re-baseline (all five)** — copy from `docs/templates/shared/`:
   `atrium_paradata.py`, `atrium_document.py`, `atrium_document.schema.json`, `para_licenses.py`
   where present; take `test`'s `para_config.txt` / `setup/para_config.txt` version and
   `CITATION.cff`; restore nlp's `100755` modes.
3. **Service port** — nlp + pc: re-baseline only (plus `service/requirements.txt`,
   `setup/config.txt`). llm-enrich + translator + alto: port `service/*.py` from `test` verbatim
   with the accretion path and its runtime deps.
4. **Skill layer** — `SKILL.md` documents the accretion param + response field;
   `scripts/atrium_<verb>.py` gains the matching flag (stdlib-only, §6/Appendix B; translator
   additionally parses `multipart/mixed`); `service/README.md` refreshed from the template;
   re-run the §12.2 step-2 anti-pattern checklist.
5. **Land** — push, one green `skill-validate` per branch, merge to `agent-skill`, tag
   `skill-v<para_config version>` (§12.2 step 5).

**alto judgment call (recommended): retire the fork.** Carry `test`'s `text_util.py`,
`extract_JSON_2_TXT.py`, `document_hook.py` and full `service/utils.py`; delete
`text_util_langID.py`; take `text_api.py` + `text_inference.py` byte-identical. §5 specifies
`service/` as "unchanged from the default branch", and the zero-dependency constraint binds only
`scripts/atrium_postprocess.py` — so ~900 extra source lines cost nothing while permanently
removing the drift generator. Fallback if the fork stays: port only the
`document_record`/`document_json_out` hook and record the `process_json` omission as an
intentional §12.2 divergence, accepting that `/openapi.json` will not match `test`.
