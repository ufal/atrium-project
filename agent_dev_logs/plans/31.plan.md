## Context
The `agent-skill` branches are trimmed derivatives of the default branches (§5), kept current by
porting `service/` changes forward **by hand** — for alto-postprocess, nlp-enrich and
page-classification there is no merge base at all, so `git merge` is unavailable and `git log`
cannot answer "how stale is this branch?".

This is a **recurring** sync, not a one-off: the 2026-09-08 pass aligned all five, and `test`
moved again on the morning of 2026-09-09 (the #51 SKOS registry, plus dependency pins), putting
drift back to 0/5 within a day. The cost of a cycle is therefore what matters, and the leverage
is in the diagnosis tooling rather than in any single port.

Decisions locked (2026-07-29, still in force):
1. **Manual landing, scripted diagnosis** — close drift by hand per §12.2; `skill_drift_check.py`
   and `skill_ify.py` do the diagnosis so the next sync is cheap.
2. **Port features fully**, including the runtime modules they need.
3. **Full contract check in CI** — step 4, both passes.

Added 2026-09-09:
4. **Deliberate divergences are declared, not remembered.** `DOCUMENTED_DIVERGENCES` in
   `skill_drift_check.py` carries the path and the reason, so a clean run keeps meaning
   "nothing unexamined". The bar is that the skill branch is right and the default branch has
   nothing to fix.
5. **Skill-branch fixes take a shape the default branch could adopt unchanged.** The
   `/frontend` mount is `.exists()`-guarded so it is a no-op where the directory is absent —
   a divergence with a retirement path, not a fork.

## The three defects worth remembering
1. **A default that silently degrades is worse than a missing input.** `app-import` and
   `primary-endpoints` both have defaults; omitting them looked like "taking the defaults" and
   was in fact turning half the check off. Alto's step 4b import-skipped on every run behind the
   `::warning::` meant to prevent exactly that misreading. *If a workflow input changes what is
   asserted, it should be `required: true` rather than defaulted.*
2. **An allowlist is a blind spot with a good reason attached.** `Dockerfile` and
   `docker-compose*` are content-allowlisted because skill images are legitimately retargeted —
   and that is what hid every branch dropping the issue-#55 `HEALTHCHECK`. The fix is not to
   un-allowlist the diff but to check the *contract* separately.
3. **"Common files differ" cannot see a file that is not there.** nlp-enrich was reported clean
   while CI failed on a `service/` file it did not carry.
