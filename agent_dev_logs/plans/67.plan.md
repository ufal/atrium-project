## 1. What this plan closes

#67 does not track repository work; its sub-issues do. It defines the pilot integration contract:

```text
AMČR seed
   │
   ├── scanned path
   │      page-classification → ocr-postprocess → nlp-enrich → keyword-extract → translator
   │
   └── born-digital path
          digital-convert /reformat ──(needs_ocr pages: Temporal → OCR → ocr-postprocess /process page=)──┐
                                    └──────────────────────────────────────────────────────────────────────┴→ nlp-enrich → keyword-extract → translator
```

The route itself (Temporal) is AMČR's. The tools guarantee that each stage accepts and returns the same record and stamps only its own blocks. _(superseded 11-11: D1, no stamps; one `run_uuid` per block)_
