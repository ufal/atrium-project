### Design rules
1. **One shared generation (gen 3).** It lands in the hub `docs/templates/shared/` first, then
   `scripts/revendor_shared.sh` runs in all five repos, then `v1` moves. A new canonical `.py` must already be a fixed
   point of `ruff format --isolated --line-length 120` (the 09-26 para-drift lesson).
2. **Open strings in responses, not enums.** A new value then never breaks an older generated client. **Request** enums
   only where the handler already refuses unknown values: alto `task_type` after the fix, nlp `kw_method`/`lang`/`format`,
   translator `response_format`/`output_mode`.
3. **The runtime output does not change.**
   - Routes declare `response_model=None` explicitly (it stops FastAPI inferring a model from `-> Dict[str, Any]`) and
     add `responses={200: {"model": X}}`. pc `/predict_image` keeps its model.
   - A field the handler always emits has no default, so it is **required** and its removal is a breaking change.
   - The contract tests validate real `TestClient` bodies against the **published** schema.
4. **Every error is declared.**
   - App-wide: `FastAPI(responses=error_responses(422, 500))`. This also suppresses `HTTPValidationError`.
   - Per route: 413, 415, 429 (with `Retry-After`), 502, 503 and 504, as each route can raise them.
   - Post-processing drops 422 from operations with no parameters and no body. `/health` and `/ready` keep their own
     503 bodies.
5. **The spec is stable.**
   - operationIds are the route function names (`generate_unique_id_function`).
   - `root_path_in_servers=False`.
   - No `-Input`/`-Output` component names.
6. **The record is typed once, by reference.**
   - `AtriumDocument` is a `RootModel`. Its component body is replaced by the vendored `atrium_document.schema.json`,
     with `$defs` hoisted as `AtriumDocument_<name>`.
   - **Only responses** use it. Multipart record parts stay binary with `contentType: application/json`, and
     JSON-body records stay free-form objects, because a #67 R1 seed fails the full schema.
7. **The spec depends only on the code.**
   - Nothing read from the environment reaches it (nlp's `DEFAULT_KW_METHOD` moves out).
   - `fastapi==0.141.1` and `pydantic==2.13.5` are pinned in every file a lane or image installs.
   - A test checks that the installed versions equal the pins, and that the spec is the same with every `[limit]`
     variable set to a non-default value.
8. **The registry grows by cause, not by detail.**
   - New codes: `unsupported_media_type` (415, with an `accepted` member), `invalid_record` (422) and `ocr_text_layer`
     (422). `REASON_STATUSES` fixes each code's statuses.
   - Finer causes, such as alto's reader codes, go into an unregistered `cause` member.
   - `invalid_record` covers only a record that does not parse, is not an object, or has an unsupported
     `schema_version` major. A schema-invalid baseline is still accepted, with `document_json_schema_error`.
