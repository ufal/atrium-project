## 1. What #53 is now
#53 is the closed-out operational baseline for every ATRIUM service:

```text
service API
├── PORT / HOST / GRACEFUL_SHUTDOWN_S / RELOAD from the environment
├── /health = liveness, /ready = readiness, /info = identity + effective limits
├── SIGTERM drains; Dockerfile has STOPSIGNAL + HEALTHCHECK
├── every limit an environment setting; refusal or a limits_applied note, never a silent cut
├── errors in the shared {status, reason, detail[, limit]} shape with registered reason codes
├── external endpoints configurable
├── stream logs in the agreed shape (#61)
└── batch/CLI and research targets outside the -api image
```

All six current services carry it: page-classification, ocr-postprocess, digital-convert, nlp-enrich, keyword-extract, translator. The shared modules live in the hub and are drift-checked.
