## The three-format rule, as revised by #84 (11-12)
- **JSON** (`atrium/document-json`) is the canonical record: identity, text in lines, and what the steps add; no
  run data and no copy of the layout.
- **Layout** is `atr/docproc-json`, written by digital-convert or the ATR, one stored per document (D20, D22). No
  ALTO is produced or stored (D24); an ALTO export only if a consumer needs it.
- **TEITOK** stays the standard linguistic output (`atr/teitok-xml`), its layout taken from the record or docproc;
  its limits are stated (boxes at block level where the ATR gives no lines, `bbox_precision`).
- **Markdown** with cues stays the LLM input and a development output; never stored, never carrying `enrichment`
  back to the model.
- Entities and keywords live in the record.

## The three-format rule (08-01) _(superseded 11-12: revised by #84, above)_
- **JSON** (`atrium_document`) is the canonical record.
- **Markdown** with cues is the LLM input. It never carries the `enrichment` block back to the model.
- **TEITOK** is the spatial/linguistic form.
- Entities and keywords live in the record.

## Reassessment after the pilot
Reassess when all of these hold:
1. the six-stage map has run end to end in the pilot _(11-12: the chain of the contract of 12 November, assembled step by step)_;
2. keyword-extract's controlled path is evaluated (keyword-extract#2), or a decision not to ship it is recorded;
3. #22 is done or dropped;
4. AMČR has pilot evidence on what further LLM use is wanted.

Already met: one owner, the vocabulary artefact, a clean digital-convert, the stress suite.

Then choose one outcome:
- **close**, because the scope is absorbed by concrete issues;
- **reopen narrower**, for named post-pilot applications;
- **stay deferred**.

## Must not be reintroduced
- A second LLM or vocabulary implementation (in nlp-enrich, digital-convert or elsewhere). The translator's translation backend is the agreed exception (#72).
- Research or benchmark code in production images.
- Entities or keywords copied into the Markdown input.
- Multi-GPU/H100 work as pilot scope (#26/#27 stopped).
