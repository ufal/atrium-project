## Decisions

**A. Which classifier result goes into the paper: decided (Kate, 10-21).** The `vX.4` models, re-run on the test
sets of the LINDAT dataset, which are held out from training by design, with the
[page-classification#61](https://github.com/ufal/atrium-page-classification/issues/61) fix (without it, an
unreadable image shifts every later prediction, and `-tn 1` writes class numbers as scores). Each run is checked with
`data_scripts/eval_by_document_overlap.py`, which must find no training page, and gives top-1 for pages of documents
seen in training and for unseen documents. If the numbers are not there by 10-25, the stored per-fold test
partitions (4,823 pages per fold) stand in, saying that the split is by page.

The 99.16 % of motyc's brief is not used. It was measured on the 5,449-page evaluation set, which was meant to hold
only pages no fold trained on; the script that selected it (`result/stats/unused.sh`) compared names as text and
missed zero-padded page numbers and ids with a letter, so 4,296 of its pages are training pages in fold 1 (#15; the
script is fixed and leaves 130 pages).

**The figures (10-22), for Table 2 after the co-authors' review (#15):** top-1 on each model's held-out fold —
`v1.4` 95.87 %, `v4.4` 95.81 %, `v5.4` 95.58 %, `v3.4` 95.49 %, `v2.4` 94.64 % (4,791–4,795 pages each, 95 %
intervals about ±0.6); on pages of unseen documents 93.87–95.60 %; top-3 99.75–99.90 %. The split is by page, and models
on the same fold do not differ significantly. The table is in [`15.revision_brief.md`](15.revision_brief.md) §1.

**B. Corresponding author.** motyc proposed David Spáčil. He signs the cover letter and the letter to the chairs;
until he answers, the drafts carry a placeholder.

**C. How the code is cited (by 10-27).** CAA asks for data and code with the paper. The data has LINDAT handles. The
tools have release tags but no DOIs. Either cite the release tags and the repositories (enough for the paper), or
archive the releases with a persistent identifier (Software Heritage, or Zenodo's GitHub integration) before
10-30. The authors choose; the second needs an external action.
