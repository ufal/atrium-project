**Description:**

````markdown
Maps archival text onto controlled archaeological vocabularies with a large language model, and converts born-digital documents into the ATRIUM document record.

**Vocabulary keywords.** Each text line (CSV, TEITOK) or each passage of a whole document (TXT, Markdown) is tagged with a term from the AMČR heslář and the TEATER thesaurus, with Czech and English keywords and a confidence score. The answer is held to the vocabulary: the term list becomes the enum of a JSON schema, decoding follows that schema where the backend supports it, and a category that is not in the vocabulary is dropped, not guessed.

**Born-digital conversion.** PDF and DOCX files with a usable text layer become the document record (JSON) without OCR.

Models run locally (transformers or vLLM, one or more GPUs) or through OpenRouter or Ollama. Every enrichment run writes a paradata JSON log. Command-line tools and container images, including a REST API (`ghcr.io/ufal/atrium-llm-enrich-api`).
````
