## Context
The pilot hands AMČR one record per document and one `CreateAction` per run. AMČR seeds the record before the first stage (`doc_id` = its file id, `source.sha512` = the Fedora digest, file name, media type), calls the services from Temporal, and writes the result once. The baseline is RO-Crate 1.2 with Process Run Crate 0.5.

The acceptance proof is a seeded run:
- identity survives every stage;
- each stage contributes its own machine-readable provenance;
- the final record crate validates in CI.

Since 2026-10-04 the born-digital branch has added two kinds of co-contribution to the contract: scoring (W3) and the per-page OCR hand-off (W4). Both are now shared-module rules.
