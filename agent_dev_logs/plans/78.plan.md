## 2. Monitoring (ÚFAL, before the pilot)

1. **A scheduled live lane** per LINDAT-using tool (#81 tier 4): daily, a fixed set of short Czech texts,
   several requests each so that more than one server behind the load balancer is reached. It checks that
   numbers and vocabulary terms are kept, that the reply is in the target language, and that a known sentence
   keeps its expected lemmas and entities. A failure opens or updates one issue, as the E2E lanes do.
2. **The pilot's own signal:** the share of re-requested translation replies and of `upstream_unavailable`
   answers, read from the paradata of a day's runs. AMČR sees it in the runbook's results table (#77).
3. What it still cannot catch: a fluent wrong translation. That needs people reading samples, stated as a
   known limit.
