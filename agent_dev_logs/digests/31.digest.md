## 🩺 Drift found
- **Accretion (#13) absent from the skill services.** Paths match but parameters and response
  bodies do not, so the runtime `/openapi.json` differs: llm-enrich `/extract_keywords` +
  `/extract_keywords_text` take an optional `document_json` and return the accreted record;
  translator `/translate` takes `document_json` and answers `multipart/mixed`; alto `/process`
  takes `document_record` and returns `document_json_out`. `atrium_document.py` is missing from
  **all five** skill branches although `test`'s services import it.
- **Shared files stale.** `atrium_paradata.py` lacks `get_license_block()` on every skill branch
  — the method `test`'s llm-enrich `api.py` calls. Hub `para-drift.reusable.yml` now guards
  `atrium_document.py` + `atrium_document.schema.json`, absent everywhere on the skill side.
- **Version lag** (`/info.version` per §4.6): llm `v0.2.0` vs `v0.4.0` · alto `v1.0.0-beta` vs
  `v1.4.0-beta` · nlp `v0.16.1` vs `v0.18.0` · translator `v0.8.1` vs `v0.10.0` · pc
  `v1.5.1-beta` vs `v1.7.0-beta`.
- **alto keeps a forked classifier** — `text_util_langID.py` (1560 ln) in place of `test`'s
  `text_util.py` (2455 ln), `service/utils.py` at 128 ln vs 271. Costs it `process_json` and
  `.json` input, which is OpenAPI-visible. This fork is what generates the recurring drift.
- **`SKILL.md` documents none of it** — zero `document_json` refs across all five (111–131 ln).
- Cosmetic: nlp mode drift `100755`→`100644` on `service/{enrichment,test_api}.py`; `test`'s alto
  `text_api.py` carries a dead commented-out `/process` block (~line 244).
