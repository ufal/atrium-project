## 🩺 Findings from the nlp-enrich pass
nlp-enrich looked like a zero-drift repo — its `service/api.py` matched `test` byte-for-byte.
It was not. `service/enrichment.py` shells out to `run_pipeline.py`, which drives `api_*.sh` and
`api_util/` — **service runtime reached by subprocess, not import** — and all of it had gone
stale. Three real defects:
- **A preflight demanding a file that exists nowhere.** `api_util/api_common.sh` still ran the
  pre-FIX-#11 loop requiring `analyze.py`, absent from `test`, `agent-skill` *and* `master`.
  `api_util/manifest.py` and `api_util/nametag.py` existed only to satisfy that stale preflight.
- **The skill service ran an older NER model.** `config_api.txt` pinned `MODEL_NAMETAG` to
  `nametag3-czech-cnec2.0-240830` against test's `nametag3-multilingual-onto-260521`; the key is
  outside `_derive_config`'s override set, so it passed through verbatim. (The alarming-looking
  `OUTPUT_DIR="../../ARUB"` and missing `PARADATA_DIR` are overridden per workspace — harmless.)
- **Undeclared headline dependencies.** Root `requirements.txt` omitted `yake`, `keybert` and
  `sentence-transformers` while `keywords.py` imports all three — and `service/requirements.txt`
  documented itself as sitting on top of a root file that "already pulls in" exactly those.

**A defect on `test`, not the skill branch:** nlp-enrich's `test:service/requirements.txt` holds
`pytest`/`pytest-cov`/`openapi-spec-validator` — test dependencies mislanded into the service
file, the same defect class #32 hit on llm-enrich. The skill branch keeps the correct
fastapi/uvicorn/python-multipart set; this is the one intended divergence, and `test` needs fixing.

**Frontend claims that no code implements** (surfaced by step 4's development): llm-enrich and
translator branch READMEs both state a demo frontend is "mounted at `/frontend`", and both ship
`service/frontend/{index.html,script.js}` — but neither `service/api.py` mounts anything. alto
mounts `/static`, not `/frontend`, on **both** branches, so the 2026-07-22 "unified
`/static`→`/frontend`" never actually landed.
