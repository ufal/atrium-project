## ⚠️ Limits

- **Benchmarks are vendor-reported.** Only local results on archive data decide anything.
- **The output is constrained, not correct.** A decision model cannot leave its option list, but it can pick the wrong
  option. Every child counts `invalid` answers and timeouts, and sets its thresholds on dev.
- **The internal endpoint is one shared machine running an 8-bit build.** Its figures are not the card's bf16 figures,
  and a full-corpus run is sized from measured throughput.
- **No record field exists for any result.** #71 is closed, so any field is a new hub issue and a class (c) change
  with AMČR's agreement.
- **The meeting of 11-11 also carries the pilot's approvals** (#77, #78, #79). If there is no time for these five
  questions, they can be answered in writing on the issue.
