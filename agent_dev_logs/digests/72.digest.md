## 🎯 Goal
Independently deployable production services, each image carrying its stage and approved shared components only:

1. one production service per stage;
2. governed shared layers: one document reader, one LLM access layer, one versioned vocabulary artefact;
3. no duplicate LLM/vocabulary code; research off the release line;
4. `para-drift` over the shared layers;
5. PyMuPDF replaced in page-classification after comparison;
6. AMČR vocabularies and TEATER declared CC0;
7. the established `/health`, `/info`, limit and error conventions kept;
8. branch protection, immutable release tags, trusted workflow references; the GPU runner deferred.

**Acceptance:**
- production images contain only their stage + approved shared components;
- shared layers are drift-checked;
- no production image carries the undeclared AGPL dependency;
- vocabulary/licence metadata match the AMČR baseline;
- release tags cannot be silently retargeted;
- the service layout is the baseline the processing/trust gate consumes.
