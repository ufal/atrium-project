## 🔎 Distinctions
1. Synthetic fixtures (`CTX000000001–3`) are not ARUP/B copies.
2. An id in a manifest or a keys-only sidecar is not a copy of the text.
3. Vocabulary artefacts (AMČR/TEATER, CC0) are a separate class (#6/#51).
4. Derived text is a copy of the content. A JSON record or Markdown that carries `original_text` or the full page text counts, like the source file.
5. Git history and issue attachments survive a deletion from the tree.
