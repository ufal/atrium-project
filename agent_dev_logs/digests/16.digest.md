## 🧭 2026-10-02 refresh — what changed

The old digest was based on the pre-split world of four main tool repositories. The current ATRIUM hub lists six product repositories:

- `atrium-page-classification`
- `atrium-ocr-postprocess`
- `atrium-translator`
- `atrium-nlp-enrich`
- `atrium-keyword-extract`
- `atrium-digital-convert`

The hub README describes `atrium-ocr-postprocess` as the continuation of `atrium-alto-postprocess`, and `atrium-keyword-extract` plus `atrium-digital-convert` as continuations of the former `atrium-llm-enrich` split. However, GitHub repository metadata still reports both predecessor repositories as **not archived**, and [#72](https://github.com/ufal/atrium-project/issues/72) still contains the request to archive them or at minimum put an explicit moved notice on them. They therefore remain relevant public locations until that lifecycle work is actually completed.

The repository split also changes the data inventory itself:

- `atrium-ocr-postprocess/data_samples/` is explicitly documented as **synthetic-only**.
- `atrium-keyword-extract/data_samples/` contains synthetic `CTX000000001–3` derived tables plus AMČR/TEATER vocabulary artefacts; no new ARUP/B source-document corpus was found there.
- `atrium-digital-convert/data_samples/` contains taxonomy/vocabulary artefacts, not committed PDFs, images or other ARUP/B source documents.
- `atrium-nlp-enrich/data_samples/` still contains only the three synthetic ALTO fixtures in its committed ALTO directory; its `manifest.tsv` mentions historical real `CTX...` identifiers, but the referenced source files are not present in the committed `data_samples/` tree.
- `atrium-page-classification` no longer uses the old `data_samples/` location in the current tree; the live sample footprint is `small_data_samples/`. At the current `test` head there are **229 PNG files** there.
- `atrium-project/fixtures/e2e/` now contains five fixture pairs: three synthetic documents and two real scan fixtures used by the E2E smoke workflow.
- `atrium-translator/data_samples/my_documents/` still contains **16 source files**: 15 AMČR metadata records plus one anonymized ALTO sample, together with translation outputs and paradata.

## 🎯 Goal

ARUP/B provided CU with copyrighted data for internal use and model training. The issue records every current storage location so ARUP/B can know where copies exist and can safely remove copies when the project ends; unapproved public copies are to be withdrawn as soon as possible.

This issue answers **where copies are**. It does not replace the licensing record in [#21](https://github.com/ufal/atrium-project/issues/21) or the tooling/model licence audit in [#6](https://github.com/ufal/atrium-project/issues/6).

## 🔎 Important distinctions for the inventory

1. **Synthetic fixtures are not ARUP/B source copies.** The `CTX000000001–3` samples in `ocr-postprocess`, `nlp-enrich` and `keyword-extract` are fictional/synthetic and are used to exercise contracts and pipelines.
2. **A historical identifier in a manifest is not the same as a committed source file.** `nlp-enrich/data_samples/manifest.tsv` still mentions real-looking `CTX...` IDs, but the current committed ALTO tree does not contain those documents.
3. **Vocabulary artefacts are a separate class.** The AMČR and TEATER vocabulary is now maintained with the keyword-extraction stack; its ownership/licence is covered by #6/#72 and should not be conflated with the ARUP/B source-document inventory here.
4. **The successor split does not automatically erase predecessor locations.** `atrium-alto-postprocess` and `atrium-llm-enrich` still exist publicly and are currently not archived at GitHub. Until that changes, they remain part of the visibility/copy story even if their current sample trees are synthetic or vocabulary-only.
5. **The page-classification footprint has changed path and count.** The current repository uses `small_data_samples/`, and the current `test` tree has 229 PNGs; the older `data_samples/` wording/count in the May/June thread is therefore historical.
