## 🔁 Four follow-on defects — each surfaced *by* a gate this round installed

The round's defining signal: **every mechanism, once actually wired, immediately caught something real that had been invisible.**

**(a) Formatting split the vendored canonical file.** Tool repos run `ruff-format` on pre-commit, the hub does not, and `line-length` is not uniform (**100** in nlp/llm, **120** elsewhere) — so a shared file's bytes were a function of *which repo committed it last*, and `para-drift` went red in three. Each variant is a fixed point of its own config, so re-vendoring alone would not have held. Fixed with `[format] exclude` **plus `force-exclude = true`** — the flag is load-bearing, because pre-commit passes explicit paths and ruff otherwise honours exclusions only while walking directories.

**(b) The schema gate caught a *released* image.** It rejected `entities[].type_cnec: null` from nlp-enrich **v0.18.2**. The fix was already on `test`, but `:latest` moves **only on a version tag**, so no source change could green the nightly. Addressed by reporting *every* violation with owner attribution, and publishing a moving **`:test`** tag so the E2E can judge what is about to ship. Cleared by the release wave.

**(c) The cross-stage `doc_id` assertion caught a fork from a *correct* derivation.** The translator emitted `CTX000000003-1` while four stages said `CTX000000003` — its input really was `PAGE_ALTO/<doc>/<doc>-1.alto.xml`, so `canonical_doc_id()` answered accurately **for that file** and wrongly **for that record**. No filename rule can close that (`sbn.2019-1` is a legal name). Resolution is architectural: **`DocumentRecord` inherits the baseline's `doc_id`** — the originator names the document, later stages inherit, derivation applies only with no baseline.

**(d) The coverage ratchet exposed two modules that had never been tested in CI.** Raising `fail_under` turned llm-enrich red at 58.20%. The immediate cause was a bad floor (see *Corrections*), but the number was reporting something true: **17 tests were skipping in CI** on absent optional deps — and only 3 were new. `tests/test_pdf_to_md.py` (4) and `tests/test_docx_to_md.py` (10) had been skipping **since they were written**, leaving `docx_to_md.py` at **15 %** coverage behind a green tick. Declaring `pdfplumber` + `python-docx` in `requirements-test.txt` makes all 17 run: `pdf_to_md` 41→77 %, `docx_to_md` 15→74 %, `digital_to_json` 77→94 %, total 58.20→63.55 %.

> The lesson: **(c) could not have been found by deriving harder, and (d) was not a coverage problem** — both were paths nothing exercised.

## 🆕 Phase 5 — the `digital-convert` originator (built this round)

`atrium-llm-enrich/api_util/digital_to_json.py` (~570 lines) + 29 tests. §1a had arbitrated between two possible originators since 08-03 while **only one existed**, so the contract was enforced against a case that could not arise. It now can.

Four layers per `18.plan.md` §2 — extraction (lazy `pdfplumber`/`python-docx`), normalization, serialization, output gate. Notable:

* **The decode-sanity gate is the point.** Born-digital ≠ trustworthy: CP1250 bytes read as CP1252 make `sondě`→`sondì` with no exception, no length change, and `Zpráva` intact. The confusion table is **derived from the two codecs at import time**, so it is provably exactly the disagreeing bytes whose CP1250 reading is Czech — and it explains its own omissions (`á`, `é` coincide, which is *why* "Zpráva" survives). Recovery reproduces the intended text exactly, which is what makes the diagnosis a diagnosis rather than a suspicion.
* **A ratio alone provably cannot catch it** — the observed line scores **0.913** (4 misreads in 46 letters), above any cut loose enough to spare clean text. So the module keeps two separate signals: the 0–1 `quality_score` the schema documents, and a ≥2-hit rule, justified because Czech contains no `ì`/`è`/`ø`/`ù` at all.
* **It reports, never repairs** — rewriting text would make `source.sha256` describe a document whose text no longer matches it. Output is `categ="Garbage"` (the exact `DROP_CATEGORIES` spelling) plus `needs_ocr`/`needs_ocr_reason`, which is what *authorises* alto to re-originate the plane.
* Two bugs its own tests caught pre-merge: `page_index` written 0-based against a `minimum: 1` schema, and a paragraph splitter using the *median* gap — which on the measured fixture (2.0 vs 34.0 pt) sits **above the break it exists to find**.
