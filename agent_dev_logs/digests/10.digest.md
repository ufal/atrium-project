## ✅ §2 · What the 2026-08-19 round found and fixed

The round's defining shape: **six of its nine findings were mechanisms that could not fail.** Not absent gates — present ones, green, checking something other than the thing that mattered.

### Correctness

* **`set_source()` silently discarded new sub-keys.** When a baseline arrived carrying a *partial* `source` — `sha256` + `filename`, no `origin`, which `page_split.py` explicitly anticipates — a later `set_source(origin=…)` was a complete no-op: no key collided, so nothing was written and nothing complained. The record could never learn its origin, and §1a's deferred check never resolved. **This reintroduced, through a different door, the exact permanent abstention the 08-06 round had just removed from alto.** Reproduced with a control: with a partial `source`, `alto-postprocess` wrote `lines` onto a born-digital record under `strict=True` in silence; with no `source` at all, the identical call raised. Fixed so an absent key is additive while a written key stays immutable — re-running the reproduction now raises in both arms.
* **The converters** (`digital_to_json.py` +118, `docx_to_md.py`) and **`atrium_document.py`** ×6 copies, re-vendored byte-identical.
* **alto/translator coverage `omit`** no longer hides `service/*`.

### Gates that could not fire

* **Scheduled runs were being cancelled by pushes.** Every `concurrency` group was keyed `<workflow>-${{ github.ref }}`, so a scheduled run and a push run on one ref shared a group — and with `cancel-in-progress` the push won. On 2026-08-19 that cancelled `all-repos-smoke` run #32 **eleven seconds** before a push run started. A cancelled run reports no failure: the nightly stops producing a signal without ever going red.
* The fix is the part worth recording: it landed as a **new check in `tools/ci/workflow_lint.py`**, not as a hand-edit. The check accepts either remedy — scope the group by `github.event_name`, or set `cancel-in-progress: false` — and it now runs against all six repos on every push.
* **`sys.modules` poisoning in test suites** (pc: four files stubbing `atrium_document`; alto: session-wide fake `torch`/`transformers`) — removed in pc, so skips stop lying about why.
* **Action pins** restored across the hub after a revert had left `e2e-pipeline-smoke.yml` as the only file in six repos on stale majors.

A tag's current target says nothing about its history, and there is no history API for a lightweight tag. Job-step evidence showed nlp's `build-and-push` had run and promoted release tags at 04:03 UTC, and an anonymous GHCR probe returned 200. **The recommendation built on it — "one more push to nlp-enrich" — was unnecessary work.**
3. Both corrections have the same root: **a claim about live state was derived rather than measured.** The check that caught each was cheap and available the whole time.
