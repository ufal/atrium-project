## 🎯 Decision (09-30, relaying #67's "Reshape: into a bounded CI check")

> reshape this into a bounded CI quality check rather than a general-purpose LLM code reviewer. The check may inspect a defined set of repository properties, but it must remain deterministic enough for CI and must not become an additional production-quality gate for the ATRIUM services.

The shape:
- one reusable workflow in the hub, called by the six tool repositories (the hub is the host, not a seventh caller);
- the review unit is one PR into `test`;
- the output is advisory file/line comments;
- the deterministic gates (tests, OpenAPI contract, para-drift, lint, security, release) stay authoritative.
