## 🧭 What already exists that Galaxy work can reuse (2026-09-24)
- **Container images** on GHCR for every tool, built by the hub's reusable Docker workflow (llm-enrich also publishes
  `-remote` and `-digital` variants); the E2E runs them in sequence (run 35990199050 green).
- **Per-tool I/O descriptions**: the hub site's *Pipelines* page (stage table, W11 format adaptation), alto-postprocess's
  `docs/text_inputs.md` (*Formats and their standards*: every input format it reads, with standards and producers) and
  nlp-enrich's README § "TEITOK XML" (TEITOK as an output, its composition, tools, pitfalls) — the input/output formats
  a Galaxy tool must declare.
- **Licences** per component in each repo's `para_config.txt`; flexiconv (GPL-3.0-or-later) is a CLI step and never in
  a service image, which also applies to any Galaxy container.
- The SSH Open Marketplace records themselves (hub #4, #17): the 09-07 comment on #4 lists what they still lack
  (DMP-standard steps, I/O per step, formats, provenance, PIDs; no llm-enrich record; no born-digital workflow).
