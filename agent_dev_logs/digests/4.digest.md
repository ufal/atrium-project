## 🧭 2026-09-30 → 2026-10-02 — why #4 has to be rewritten again

The 30 September meeting changed the repository ownership of three parts of the old chain:

*   **atrium-alto-postprocess → atrium-ocr-postprocess:** the same OCR post-processing pipeline now explicitly accepts several OCR formats and any text-bearing input; the SSHOMP record `YParYU` must follow the new repository identity.
*   **atrium-llm-enrich → two current repositories:**
    *   **atrium-keyword-extract** owns both statistical keywords and controlled AMČR/TEATER keyword extraction; the existing SSHOMP record `j9fqxo` should be re-pointed, not duplicated.

*   **atrium-nlp-enrich** keeps the LINDAT-based NLP stage (UDPipe, NameTag, TEITOK and record projection) and no longer owns the keyword-extraction stage.

This is now explicit in the hub `README.md`, the six Workflows narratives, and the current #67 integration baseline. The hub's `docs_site/workflows/index.md` is the canonical current inventory and already lists all six tools.
