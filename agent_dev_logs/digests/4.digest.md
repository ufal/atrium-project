## 🔎 What the 2026-09-25 check found
**How:** the marketplace API host is blocked from the agent session, but each record's web page embeds the full
approved item. Every field was read and compared with the repositories at their current releases. Version `106039`
of `0xSpVP` is not public until approved and could not be read.

### Across all four tool records
- **Version** field is `v1.0.0` on all four. The repositories are at page-classification `v1.8.0-beta`,
  alto-postprocess `v1.5.1-beta`, nlp-enrich `v0.21.0`, translator `v1.1.0-beta`.
- **No `license` property.** Licences appear only in the description tables; SSHOMP recommends the SPDX licence
  property for tools. The code of every repository is MIT.
- **No related items.** None of the four links another ATRIUM record, `0xSpVP`, or the third-party records above.
- **Actors:** only Straňák (Curator or Reviewer) and Novák (Curator or Contact). Kateryna Lutsai, first author in
  every `CITATION.cff`, is not listed; of the two, only Novák's actor carries an ORCID.
- **No API images.** Mode of use is `Command line` only. Every tool now publishes a REST API image
  `ghcr.io/ufal/atrium-<tool>-api` (hub #55, 09-07 → 09-09), later than the July texts.
- **Licence tables** in `RER7Fw` and `YParYU` carry source markers (`[2]`, `[1]`) whose references were not copied.
- **TRL** is `4 - technology validated in lab` on all four (`0xSpVP` says 3).

### Per record
- **`RER7Fw`** — two wrong licence rows: "LINDAT Dataset — Public Domain / CC0 — 🟢" (the dataset is **CC BY-NC 4.0**:
  `setup/para_config.txt`, README, and the #21 re-release) and **DeepDoctection** (no code imports it —
  `tests/test_para_config.py:30`; only the failed v0.1.0 draft used it). **Ultralytics** (AGPL-3.0, `--yolo`) is
  missing. The external ID `hdl:20.500.12800/1-5959` is the original dataset handle; the corrected release is
  `1-6184`. No input/output formats. 1,849-character description (guideline: about 1,500). Repository-side: the API's
  `/predict_document` imports **PyMuPDF** (AGPL-3.0), which `para_config.txt` does not list.
- **`YParYU`** — "GLM-4 (Text Base) — MIT / Apache-2.0" is wrong: the repository uses **GLM-4v-9b** under the
  `glm-4` licence. pypdfium2 (Apache-2.0) and charset_normalizer (MIT) are missing. Input is ALTO only (step 1 now also
  takes OCR JSON and PDF, DOCX, TXT and about twenty other text-bearing formats, #31); output is CSV only (also plain
  text and the ATRIUM document record). No statement that the output is CC BY-NC 4.0 at minimum (FastText is always
  used) and CC BY-NC-SA 4.0 with LayoutReader, the default reading-order method.
- **`EMhu3X`** — the description names **KER** as the keyword step; KER is now the `legacy` option, YAKE is the
  command-line default and KeyBERT the API default, and vocabulary keywords are llm-enrich's (step 8). **TEITOK**, the
  primary output, is not mentioned. The GitHub external ID is `atrium-nlp-enrich` **without the `ufal/` owner**, so the
  link is broken. No input/output formats. The table lacks YAKE (AGPL-3.0), KeyBERT, flexiconv (GPL-3.0), the
  AMČR/TEATER vocabularies (CC BY-NC 4.0) and the fact that every core run is CC BY-NC-SA 4.0. `see-also` points to the
  alto-postprocess GitHub page rather than relating `YParYU`.
- **`CizIUW`** — described as a wrapper "specifically designed for the LINDAT Translation API"; the backends are now
  pluggable (LINDAT CUBBITT by default, self-hosted CTranslate2 with EuroLLM, MADLAD-400, NLLB-200 or OPUS-MT, or an
  OpenAI-compatible LLM API). The "AISCR Teater (App) — GPL-3.0" row names software the tool does not run (only the
  TEATER data is used). Missing: UDPipe models (CC BY-NC-SA 4.0), the CTranslate2 models, NLLB-200 (CC BY-NC 4.0),
  OPUS-MT (CC BY 4.0), LLM-provider terms, and the permissive recipe. LINDAT Translation and UDPipe have SSHOMP
  records but are not related items.
- **`13eHAZ`** — a workflow with **zero steps**: the whole 3,455-character text sits in the description and reads as
  the April tool description of the translator. Stale in places ("space-aware" chunking is now sentence-aware; the
  dual-pass ALTO translation is not described). No licence table, no related items (not even `CizIUW`), no
  `accessibleAt`. #66 lists it among the records for the Galaxy wrap-up.
- **`0xSpVP` (approved text)** — still the November 2025 eight-step version with KER as step 4; `106039` replaces it
  once approved.
- **Duplicate check for llm-enrich** — not possible from the agent session (search pages render client-side, API
  blocked); to be done in the browser before creating the record.
