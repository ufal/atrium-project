## ✏️ Corrections to this digest's own previous edition
Recorded per the convention `docker_gha_roadmap.md` §8 and the 08-19 round established — the prior
edition's errors were **derivation from stale secondary sources**, which is the failure mode this
ecosystem has now hit three times.

1. **"IX. Disposability — Known violation, unresolved (B8: `uvicorn --reload` in production)"** — wrong when
   written. B8 had already been fixed (`service/text_api.py` env-gates `reload`, default false); six
   documents described it as open, corrected in `docker_gha_roadmap.md` §8 on 09-07. Factor IX is now
   fully green in code.
2. **"II. Dependencies — fixed in nlp-enrich and page-classification … whether the same class of gap
   exists elsewhere has not been swept"** — the sweep has now been done, and there is no gap: `uvicorn`
   is declared in all five `service/requirements.txt`.
3. **"I, IV, VI, VII, VIII, X, XI, XII — Not audited from any existing source."** — accurate as a
   statement about *sources*, but it left the impression that nothing was findable. Measuring the trees
   directly took one pass and produced the two reds above, one of which (VII) sits on #55's own
   acceptance path.
