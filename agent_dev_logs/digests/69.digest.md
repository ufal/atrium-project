**Why `.gitkeep` alone does not fix B6.** It makes `./data` exist with the cloner's uid, typically 1000 on Linux, while the container runs as uid 10001. The write still fails. The only fix that works is to run the container as the host uid (`user: "${ATRIUM_UID:-10001}:0"`), with the image's writable paths group-0 writable (the OpenShift arbitrary-UID convention).
