### The one red tag run, and why it is not a port bug
- **page-classification `v1.9.2-beta`**, Docker Build & Publish [37269822039](https://github.com/ufal/atrium-page-classification/actions/runs/37269822039): `docker-build-smoke (api)` failed at the `PORT=9000` step with "container reported unhealthy at PORT=9000 … so $PORT is not being honoured".
- **Cause:** the image warms five models at startup and each probe container downloaded them again; on a slow Hub day the `PORT=9000` container (the second probe container) was still loading its fifth model when the HEALTHCHECK budget ran out. The same commit passed the step on `test`, and `build-and-push` promoted the release tags anyway.
- **Fix:** hub `4cbf900` (in `v1`). One named volume at the image's `HF_HOME` is shared by the probe containers, and the error message names an unfinished warm-up. The first page-classification run with it: [37298437914](https://github.com/ufal/atrium-page-classification/actions/runs/37298437914), `PORT=9000` green in 37 s.
