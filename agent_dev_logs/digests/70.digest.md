## 🔎 What was built (2026-09-30)
**Item 1 — detail profiles.** Text lines are identical in every profile; cue sets nest (minimal ⊂ standard ⊂ full):
- `full`: every cue, plus the new `LAYOUT_MARGIN` (canvas minus the body-line union) on pages with a canvas and boxes — record route only, so `xml_to_md --format layout` on ALTO/TEITOK is byte-identical to before.
- `standard`: one `BBOX` per `group_id` block (tables keep theirs; ungrouped lines none), no `LAYOUT_MARGIN`.
- `minimal`: skeleton and structure; no geometry, `DOC_META`, `OCR` or emphasis (dropping `OCR` departs from the 07-24 §B draft on purpose: on pilot-shaped ALTO records it is the only cue there is).
- `RESERVED` names each cue no profile emits, with its reason: `INDENT`, `LAYOUT_COLUMN` (a post-freeze schema change, llm-enrich#10 W7), `FONT`/`STYLE` (#18 option (c)), `WATERMARK`, strike, underline, alignment. A test holds every catalogue cue to "in a profile or reserved".
- Measured (`scripts/detail_budget.py`): the two real hub E2E scans through `xml_to_md` layout, `standard` −35 % / −53 %, `minimal` −52 % / −64 %; the digital fixtures −20…−41 % and −52…−63 %; DOCX ≈ 0 % (no boxes).
- Fixed on the way: a `json_to_md` recipe is written only when the record can be rendered (a `.txt` upload with no baseline recorded a recipe `json_to_md` refuses), and the recipe names the record's own file when an AMČR seed keeps its id (#68).

**Item 2 — record → TEITOK projection.** `pb/@ana="#pcat-…"` + a `classDecl` taxonomy (`@corresp` = the `atrium_vocab` concept URI); llm-enrich's TEATER/AMČR categories (`@ref` = concept URIs from `teater_category_ids`, `@cert`) and cs/en keywords, and nlp-enrich's statistical keywords per document and **per page** (flexiconv#1's two major asks), in `profileDesc/textClass/keywords`, each pointing at its `<pb>`s. Header and `pb/@ana` only: `teitok_read`, `teitok_layout` and flexiconv's reader see the same text (tested). Idempotent, refuses another document's TEITOK, validated before writing. The XSD grew additively (`WRITER_FORMAT` stays `teitok-2`); `lint_projection` checks each pointer's target kind.

**Item 3 — `translation_en` reserved.** The translator runs before nlp-enrich creates `entities[]`, and nothing in the pilot asks for English entity names. The field and the grant stay (removal is a MAJOR, re-attribution breaking); descriptions only, which the freeze test treats as annotations.
