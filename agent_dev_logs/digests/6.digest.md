## 🧩 The open decision (10-02)

**The rule today.** `para_licenses` gives a record the most restrictive licence of every component the run used, tools included. stranak (10-01): "this is really NOT how (A)GPL works". A GPL renderer does not make its output GPL.

**The proposal.** Keep every tool visible in paradata, but let only the components whose content ends up in the record decide its licence: models, data and vocabularies. An unknown provider's terms (`llm_api`) stay explicit and conservative.

**What it changes.**
- YAKE (AGPL-3.0) as a keyword method would still count, because its output is in the record.
- pypdfium2, LibreOffice and flexiconv as converters would not.
- page-classification could then reconsider the training renderer if the label run asks for it.
