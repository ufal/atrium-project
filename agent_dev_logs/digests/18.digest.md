## 🎯 Goal
Provide a Docker-compose + GitHub-Action wrapper for the four ARUP-CAS CU repo forks. Opened by motyc.

## 🧠 Strategy (settled, unchanged)
Separate the **common ground** (reusable workflows, `on: workflow_call` — single source of truth in `atrium-project`) from the **per-repo differences** (thin caller workflows). Reuse rather than reinvent: `atrium_paradata.py` already reads `ATRIUM_RUNNER_IMAGE`/`REPO`/`REF`, so **GHCR-published, self-identifying containers** are the mechanism. motyc: orchestration to be discussed with rharasim; **no overall runtime wrapper needed** — containers are reachable via API. This scopes the issue to **packaging + CI**, not a runtime orchestrator.

**P0-1 — stage 5 is still dark; the secret was never added.**
In run `30512204306`, job `5. llm-enrich`: `Gate on OPENROUTER_KEY` succeeded and then **all 11 downstream steps skipped**, including `Enrich the fixture lines (OpenRouter)`. ## 🐞 Open — carried forward from the audit
1. **Mutable cross-repo pin + blanket secret inheritance.** All 20 caller refs point at `…@test`; `atrium-project` has only `main`/`test`, **neither protected**, and 4/5 callers pass `secrets: inherit`.
2. **Trivy/SBOM race the image they scan** — they run on tag push against `:latest`, published by a *separate* workflow with no ordering guarantee; `exit-code: "0"` means they never block.
3. **No GPU runner exists**, so every `slow`-marked test in the ecosystem is still unexecuted. The crons were removed on `test` so the ecosystem stops advertising coverage it lacks; provisioning remains with rharasim.
4. **Lint policy split** — blocking in alto/page-class/translator, advisory in llm-enrich/nlp-enrich.
5. **~360 lines of copy-pasted version-guard Python** across five `release.yml` files plus `security.reusable.yml`.
