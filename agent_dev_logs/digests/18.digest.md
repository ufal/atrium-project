## 🧠 Strategy (settled, unchanged)

Reuse rather than reinvent: `atrium_paradata.py` reads `ATRIUM_RUNNER_IMAGE`/`REPO`/`REF`, so **GHCR-published, self-identifying containers** are the mechanism. No overall runtime wrapper is needed — containers are reachable via API.
