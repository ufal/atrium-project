#### <img src="https://avatars.githubusercontent.com/u/20186892?u=81493d22a8cb5fce679ac0e5e32fd98a04d777c6&v=4" width="50">[motyc](https://github.com/motyc) commented at [2026-09-26 16:08](https://github.com/ufal/atrium-project/issues/6#issuecomment-5847750138):

@stranak, two findings for the licence review, as a proposal for Wednesday (see [atrium-project#67](https://github.com/ufal/atrium-project/issues/67)). AMČR decides per document licence whether a document may go to external services, so the licence each record derives has to be complete.

- [ ] **page-classification: PyMuPDF.** The service installs `PyMuPDF` (`service/requirements.txt`) for the `import fitz` in `/predict_document`. PyMuPDF is AGPL-3.0, or commercial. It is not listed under `[components]` in `setup/para_config.txt`, so a record made through `/predict_document` leaves it out of its derived licence. Either declare it there, or replace it with a permissive renderer; `pypdfium2`, which alto-postprocess and llm-enrich already use, would do. *Done when:* `para_config.txt` declares it, or the service no longer installs it.
- [ ] **flexiconv: a licence file.** The nlp-enrich service README states that flexiconv is GPL-3.0, but [ufal/flexiconv](https://github.com/ufal/flexiconv) has no licence file, so GitHub and licence scanners detect none. *Done when:* the repository carries its licence file.

On the CC BY-NC-SA question in the issue: from translator 1.2.1-beta, every translation record made with LINDAT and UDPipe states CC BY-NC-SA 4.0 (before, a one-file run showed CC BY-NC 4.0).
