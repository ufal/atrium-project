#### <img src="https://avatars.githubusercontent.com/u/65828620?u=80b39d3cb2967c52e1d4af28dcefc7a1efdfdc79&v=4" width="50">[K4TEL](https://github.com/K4TEL) commented at [2026-09-30 12:31](https://github.com/ufal/atrium-project/issues/70#issuecomment-5911358509):

All three items are resolved (commits: hub <HUB_COMMIT>, llm-enrich <LLM_COMMIT>, nlp-enrich <NLP_COMMIT>).

1. **`--detail standard|minimal`: implemented; `full` stays the default.**
   - Text lines are identical in every profile, and the cue sets nest (minimal ⊂ standard ⊂ full).
   - `standard` keeps one box per block; `minimal` keeps the page skeleton and structure only.
   - `layout_md.RESERVED` lists each cue no profile emits, with the reason.
   - `scripts/detail_budget.py` measures the saving on the two real E2E scans: `standard` −35/−53 %, `minimal` −52/−64 %. Whether a lighter default is safe for the model stays with #22.
2. **Record → TEITOK projection: implemented in nlp-enrich, opt-in and off by default.**
   - It writes page categories as `pb/@ana` plus a `classDecl` taxonomy.
   - It writes llm-enrich's TEATER/AMČR categories and keywords, and nlp-enrich's keywords per document and per page, in `profileDesc/textClass`.
   - It touches the header only and never writes line quality. AMČR's stored TEITOK is unchanged.
   - Switches: `--teitok-enrichment` / `TEITOK_ENRICHMENT`, `teitok_enrichment` on `/enrich`, `/enrich_text` and `/jobs`, and `POST /project_record`.
3. **`entities[].translation_en`: reserved, not planned for the pilot.**
   - The pilot produces English only for free-text metadata, so nothing asks for English entity names.
   - The field and the grant stay in `doc-schema-v1`; only the descriptions and `document_schema.md` changed.
