# ATRIUM born-digital converter: Galaxy tool

`digital_convert.xml` runs the command-line image of
[ufal/atrium-digital-convert](https://github.com/ufal/atrium-digital-convert) at release `1.4.5-beta`
(`ghcr.io/ufal/atrium-digital-convert-digital:1.4.5-beta`, the `digital` build target: light engine, headless
LibreOffice). It converts one born-digital document per job into an ATRIUM document record, with Markdown beside
it. A collection maps over the tool, one job per document.

`1.4.5-beta` is the first release whose entry point runs Galaxy's job script, through the hub-canonical
`container_entrypoint.py`. The job script calls `python3 /app/api_util/digital_to_json.py` by its absolute path, so
it also runs where the destination replaces the image's command (Kubernetes).

## Inputs, parameters, outputs

| Inputs     | one document: `pdf`, `docx` or `xlsx`; an optional baseline record (`json`)                                  |
|------------|--------------------------------------------------------------------------------------------------------------|
| Parameters | the pages of a DOCX (`auto`, `explicit`, `none`); Markdown on or off                                         |
| Outputs    | the document record (`json`), with the pages that need OCR flagged; Markdown (`markdown`); paradata (`json`) |

- **Names.** The document is linked as `<element identifier>.<ext>`, a `.pdf`, `.docx` or `.xlsx` in the
  identifier dropped; the record's `doc_id` is that name. The converter reads the format from the bytes.
- **Formats left out.** ODT, ODS, RTF, DOC and XLS are read by the converter too, but DARIAH's Galaxy has no
  datatype for them. DOC and XLS would start LibreOffice inside the job.
- **Not offered.** `--describe` (it calls other ATRIUM services), and with it `--classify-pages`, which has no
  effect without it; the Docling engine, which is not in this image.
- **Exit codes.** 3: an unsupported file, or a PDF that carries an earlier OCR run's invisible text (send it to
  OCR post-processing); 4: an empty, broken or encrypted file. The message is on stderr.

## Network

None: no models, no service calls. The job needs only a writable temporary directory (`TMPDIR` is set to the
job's).

## Tests

```bash
planemo lint digital_convert.xml
planemo test --docker --galaxy_branch v26.1.1 digital_convert.xml
```

Five tests: a two-page PDF (record, Markdown, paradata); a PDF with image-only pages (`needs_ocr`); a DOCX paged at
its explicit breaks (3 pages, not 4); an XLSX (one page per sheet); a PDF with an OCR text layer (exit 3).

`test-data/` holds four fixtures generated by the converter's `tests/fixtures/digital/make_fixtures.py` (byte for
byte the hashes in its `tests/fixtures/MANIFEST.json`) and `finds.xlsx`, the workbook of its
`tests/test_digital_formats.py` written with fixed zip dates. They are MIT, as `test-data/LICENSE` says.
